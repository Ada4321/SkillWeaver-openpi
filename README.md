# SkillWeaver-openpi

π0.5 fine-tuning for [SkillWeaver](https://github.com/Ada4321/SkillWeaver): the data processing and training code
used to train [π0.5](https://www.physicalintelligence.company/blog/pi05) on trajectories generated by SkillWeaver,
shown on the LIBERO-Object tasks. Built on [openpi](https://github.com/Physical-Intelligence/openpi), forked at
commit [`175f89c`](https://github.com/Physical-Intelligence/openpi/tree/175f89c); see
[Changes from openpi](#changes-from-openpi). For the original openpi documentation, see the `main` branch.

[**Project Page**](https://katefgroup.github.io/skillweaver/) &nbsp;|&nbsp;
[**arXiv**](https://arxiv.org/abs/2609.36171) &nbsp;|&nbsp;
[**SkillWeaver**](https://github.com/Ada4321/SkillWeaver)

```
SkillWeaver trajectories (NPZ) ─┐
scene task specs                ├─ examples/isaaclab_rlds/convert_npz_to_rlds.sh ──┐
instruction pools               ┘                                                  ├─ RLDS shards ─ scripts/train.py ─ π0.5 policy
LIBERO demonstrations (HDF5) ── examples/libero_rlds/*.sh ─────────────────────────┘
```

## Installation

```bash
git clone --recurse-submodules https://github.com/Ada4321/SkillWeaver-openpi.git
cd SkillWeaver-openpi
GIT_LFS_SKIP_SMUDGE=1 uv sync --group rlds
GIT_LFS_SKIP_SMUDGE=1 uv pip install -e .
```

This follows the [openpi installation](https://github.com/Physical-Intelligence/openpi#installation); the `rlds` group
adds TensorFlow for reading the RLDS shards.

## Data

The training data is the [SkillWeaver-RLDS](https://huggingface.co/datasets/Ada-4321/SkillWeaver-RLDS) dataset:

```bash
uv run huggingface-cli download Ada-4321/SkillWeaver-RLDS --repo-type dataset --local-dir data/SkillWeaver-RLDS
```

```
data/SkillWeaver-RLDS/
├── libero_object/
│   ├── train/task0 … task9/   # SkillWeaver trajectories for the 10 LIBERO-Object tasks
│   ├── val/task0 … task9/     # held-out SkillWeaver trajectories
│   └── libero_demos/          # LIBERO-Object human demonstrations in the same format
└── samples/                   # raw inputs for trying the conversion (see below)
```

The training config reads `data/SkillWeaver-RLDS`; set `SKILLWEAVER_RLDS_ROOT` to use another location. The
[dataset card](https://huggingface.co/datasets/Ada-4321/SkillWeaver-RLDS) describes the record format.

## Training

```bash
XLA_PYTHON_CLIENT_MEM_FRACTION=0.9 uv run --group rlds scripts/train.py pi05_skillweaver_libero_object \
    --exp-name=libero_object --fsdp-devices 8
```

The config `pi05_skillweaver_libero_object` (`src/openpi/training/config.py`) fine-tunes the π0.5 base checkpoint on
`train/` and `libero_demos/` with batch size 256 for 10,000 steps; we trained it on 8 NVIDIA H100 GPUs.

- **Inputs:** one exterior camera view, sampled per step among the recorded views, the wrist view, the robot state
  (7 arm joint positions and the gripper) and a language instruction sampled per episode from its instruction pool.
- **Actions:** chunks of 10 steps of 7 arm joint positions and a gripper command. The arm joints are trained as
  offsets from the current joint positions; the gripper command is absolute.
- **Normalization:** the statistics used for training are included in `assets/pi05_skillweaver_libero_object/`. To
  recompute them, run `uv run --group rlds scripts/compute_norm_stats.py --config-name pi05_skillweaver_libero_object`.
- **Validation:** every 100 steps on `val/`: `val/loss`, the end-effector position and rotation errors of the
  sampled action chunks (through forward kinematics), and end-effector trajectory plots written to
  `<checkpoint_dir>/ee_traj_vis/`.

Training logs to Weights & Biases as in openpi (`--no-wandb-enabled` to disable).

## Data processing

### SkillWeaver trajectories

`examples/isaaclab_rlds/convert_npz_to_rlds.py` turns SkillWeaver trajectories into RLDS shards, one record per
episode. It reads:

- **Trajectories:** one NPZ per episode from SkillWeaver's data collection, with RGB from several exterior cameras and
  the wrist camera, robot states and actions, and the end frame of each sub-task.
- **Scene task specs:** the task definitions of each scene, which give how an episode's sub-tasks are grouped into
  instruction segments.
- **Instruction pools:** one row per trajectory with its instructions: the overall instructions, the instructions of
  each sub-task and of each run of consecutive sub-tasks, and attribute-varied paraphrases. They are generated with
  an LLM; the language augmentation code will be released separately.

The `samples/` directory of the dataset has four trajectories with their scene task specs and instruction pools. To
convert them with the settings used for the released data:

```bash
S=data/SkillWeaver-RLDS/samples/libero_object_task0
bash examples/isaaclab_rlds/convert_npz_to_rlds.sh $S/trajectories $S/scenes $S/instruction_pool_manifest.jsonl data/sample_rlds
```

The four converted records are identical to the records of the same episodes in `libero_object/train/task0` of
the dataset, apart from the source path in `episode_metadata/file_path`.

### LIBERO demonstrations

The LIBERO-Object demonstrations are replayed in simulation with a joint-position controller and converted to the
same format; only successful replays are kept. The replay needs [LIBERO](https://github.com/Lifelong-Robot-Learning/LIBERO)
installed.

```bash
bash examples/libero_rlds/replay_libero_hdf5_to_npz.sh <LIBERO>/datasets/libero_object data/libero_npz/libero_object
bash examples/libero_rlds/convert_libero_npz_to_rlds.sh data/libero_npz/libero_object data/libero_rlds/libero_object
```

The record format is defined in `examples/isaaclab_rlds/dataset_builder.py`.

## Changes from openpi

New:

- `examples/isaaclab_rlds/`: conversion of SkillWeaver trajectories to RLDS, the record format
  (`dataset_builder.py`) and trajectory helpers (`npz_trajectory.py`).
- `examples/libero_rlds/`: replay of the LIBERO demonstrations and their conversion to RLDS.
- `src/openpi/training/isaaclab_rlds_dataset.py`: data loader for these RLDS shards.
- `src/openpi/policies/skillweaver_policy.py`: model input and output transforms.
- `src/openpi/eval/`: forward kinematics (Franka Panda, WidowX 250s) and the end-effector validation metrics and plots.
- `assets/pi05_skillweaver_libero_object/`: normalization statistics.

Modified:

- `src/openpi/training/config.py`: `RLDSIsaacLabDataConfig`, the related `DataConfig` fields, the validation
  settings `eval_interval` and `vis_ee_traj_episodes`, and the config `pi05_skillweaver_libero_object`.
- `src/openpi/training/data_loader.py`: the new RLDS dataset, a validation iterator and camera calibration
  pass-through for the trajectory plots.
- `scripts/train.py`: periodic validation.
- `scripts/compute_norm_stats.py`: support for the new RLDS dataset.
- `src/openpi/transforms.py`: `DeltaActions` / `AbsoluteActions` copy read-only inputs.
- `src/openpi/training/checkpoints.py`: synchronous checkpoint saving.
- `.gitignore`: tracks `norm_stats.json` under `assets/`.
